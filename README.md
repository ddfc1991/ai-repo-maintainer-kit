# AI Repo Maintainer Kit

A lightweight toolkit for maintainers who want cleaner README files, issue triage, release notes, and contribution docs without hiring a full-time technical writer.

This kit is built for small open-source projects that have working code but weak project communication.

## What it helps with

- Turn a rough README into a clear project landing page
- Triage GitHub issues into bug / feature / docs / support buckets
- Generate structured release notes from commits or merged PRs
- Add practical contribution guidelines
- Create issue templates that reduce back-and-forth

## Contents

- `prompts/readme-improver.md` — improve an existing README with a maintainer-first checklist
- `prompts/issue-triage.md` — classify and prioritize GitHub issues
- `prompts/release-note-generator.md` — generate user-facing release notes
- `templates/CONTRIBUTING.md` — copy-paste contribution guide
- `templates/ISSUE_TEMPLATE.md` — focused issue template
- `templates/RELEASE_NOTES.md` — release notes structure
- `scripts/changelog_from_git.py` — local changelog draft from git history
- `examples/before-readme.md` and `examples/after-readme.md` — before/after README polish sample

## Quick start

1. Copy the prompt or template you need.
2. Paste your project context into the placeholders.
3. Apply the output, then run tests or docs checks before committing.
